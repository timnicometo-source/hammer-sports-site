How to add a new searchable rulebook

  1. Save the new PDF in assets/rules/.
  2. Use this builder to generate a JSON record.
  3. Open assets/data/rulebooks.json.
  4. Paste the generated object into the main array.
  5. Commit and push both the PDF and rulebooks.json.
